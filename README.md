# Overview

This repository contains the code used to perform the analyses and generate the figures from the following [paper](https://www.cell.com/neuron/fulltext/S0896-6273(25)00557-4):

* Marino, P.J., Bahureksa, L., Fisac, C.F., Oby, E.R., Smoulder, A.L., Motiwala, A., Degenhart, A.D., Grigsby, E.M., Joiner, W.M., Chase, S.M., et al. (2025). *A posture subspace in the primary motor cortex*. *Neuron*. https://doi.org/10.1016/j.neuron.2025.07.030.

To recreate each figure from the manuscript, run the corresponding scripts in the **Paper Figures** directory. The other directories (**General**, **Utilities**, and **marino**) contain helper functions.
